# 木製プロペラ長距離飛行（MVP ステップ1〜5・海と山を越えるコース）

設計書「木製プロペラ機 長距離飛行ゲーム 設計書」8章の実装。

- **ステップ1：1区間を飛ぶ**（スロットル・ミクスチャー・燃料と対地速度）
- **ステップ2：格納庫と経由地**（A1〜A4 のセッティング、B1〜B5 の状態値、経由地での整備）
- **ステップ3：天気**（雨・雲・積乱雲・高度ごとの風・乱気流・霧・着氷・キャブレター凍結、予報の不確かさと気象ラジオ）
- **ステップ4：人の要素と評価**（E1 疲労・E2 焦り・勇気ある撤退ボーナス・最終評価）
- **ステップ5：演出と難易度**（エンジン音、空間識失調の旋回降下、パラメータごとの整備士のひとこと、難易度 かんたん／ふつう／リアル）

## 動かし方

**ブラウザですぐ遊ぶ**：https://tamtomozo.github.io/wooden-prop-flight/ （`main` に push すると GitHub Actions がテスト・ビルドして自動で更新する。設定は `.github/workflows/pages.yml`）

**手元で遊ぶ**：`npm run build` のあと `dist/index.html` をダブルクリックしてブラウザで開く（JS と CSS を埋め込んだ1ファイルなので、サーバーは要らない）。

**開発するとき**：

```
npm install
npm run dev      # ブラウザで http://localhost:5173 を開く（保存すると自動で反映）
npm test         # 計算モデル・飛行・旅全体のテスト
npm run build    # dist/index.html を作り直す
```

プロジェクト直下の `index.html` は開発用です。TypeScript を読み込むので、直接開いても動きません。
コードを変えたら `npm run build` で `dist/index.html` を作り直してください。

## ゲームの流れ

コースを選ぶ → 格納庫（セッティング・最初の行き先）→ 区間を飛ぶ → 経由地（点検・整備・給油・宿泊・次の行き先）→ … → 目的地（評価・記録・次の旅）

コースのカードには「**すぐ飛ぶ**」と「**格納庫で準備**」の2つのボタンがある。「すぐ飛ぶ」は格納庫を飛ばし、整備士のおすすめセッティング（難易度ふつう）で、いちばん近い道順の最初の行き先へすぐ離陸する（ボルトは整備士が締めた扱い。経由地からは自分で締める）。コース選びの後ろでは、選んでいるコースの最初の区間を機体がひとりでに飛んでいる（区間が終わると滑走路からやり直す）。

格納庫と経由地の画面は、見出しごとの**タブ**で切り替える（タブの名前の下に今の値、済んでいないことには赤い点）。出発ボタンはタブの外にあり、どのタブからでも押せる。
- 格納庫：最初の行き先／最初の区間／プロペラの性格／燃料の量／装備／ボルトの締め付け（難易度・遊び方・おすすめセッティングはタブの上）
- 経由地：機体の点検／操縦者／整備と準備／給油／次の行き先／次の区間（着陸の結果・霧・整備士のひとことはタブの上）

飛行中の時間は、×1 で現実の1秒がゲーム内の約1.33分（`GAME_MINUTES_PER_SECOND`）。×2・×4 で速くなる。

### チュートリアル（海ルート・山ルート）

はじめての人むけの2コース。飛行中、大事な操作のたびに**飛行を一時停止**して、**見る計器を光らせ**（ほかは暗くし、①②③の番号をつける）、計器の意味と**正しい操作**を説明する（`src/game/tutorial.ts` が中身と出す時、`src/ui/tutorial.ts` が画面）。

- **順番の説明**（はじめの区間で上から1つずつ）：進み方 → 上昇はスロットル全開 → 高く上がったら混ぜ方を薄く → 高度は目標を決めるだけ → 巡航ではスロットルを絞る → 巡航は「最良燃費」 → 燃料は「届く距離」で見る → 警告灯と操縦者の調子 → ルートバーと前方の天気
- **場面の説明**（どの区間でも、はじめてその場面になったとき1回）：雲の中・積乱雲・前方の山・山に高度が足りない・海の上・引き返し限界点・雨・乱気流・回転超過・着陸の降下・薄すぎ・キャブレター凍結（とキャブヒートを切る）・プロペラの着氷・振動・届かない・疲労
- 説明に「やってみよう」があるものは、再開したあとも画面の下に出しておき、できたら「できた！」と知らせる。済むまで次の順番の説明は出ない。止まっているあいだも操作できる
- 「わかった」（Enter / スペース）で再開、「説明をとばす」でその旅ではもう止まらない。かんたんでは、自動になるミクスチャー・キャブヒートの説明は出ない
- はじめの区間は天気なし、どの区間にも積乱雲は出ない。格納庫と経由地にも「やること」の手順を出す
- チュートリアルは自己ベストを残すが、「一日で渡りきる」「すべての空を越えて」の対象外

### コース（最初に選ぶ）

史実の大洋横断・海峡横断・山脈越えの挑戦をもとにした、**陸路では行けない**架空の海や山を飛びこえるコース。地名と地形は架空。

| コース | もとにした史実 | 特徴 |
|---|---|---|
| チュートリアル：海ルート | — | 本土の地図から海沿いの道（みなみ → はまかぜ → ぬまた → きた）を切り出したもの。2区間目で湾の上（約 65 km）を横切る |
| チュートリアル：山ルート | — | 本土の地図から山越えの道（みなみ → かわら → たかね → きた）を切り出したもの。2区間目で 1900 m の山なみを越える |
| かもめ海峡を渡る ★ | 1909年 ブレリオの英仏海峡横断 | ひと続きの海の上は 50〜100 km。まっすぐ渡るか、岬（はなさき）や島（こじま）で海の上を短くするか。朝の海霧と横風 |
| つらなり諸島を島づたいに ★★ | 1919年 NC-4 の大西洋横断（島に寄りながら） | 海の上 130〜330 km を何度も。島の滑走路は短く、整備場のない島もある。最後は霧の島（さいはて）に寄るか、330 km を一気に渡るか |
| しろがね山脈を越える ★★ | 1910年 チャベスのアルプス越え、1918年 ゴドイのアンデス越え | 海はなく、山なみが行く手をふさぐ。直行（332 km）は しろがね岳 3300 m のすぐ横を巡航 3500 m で越える（高い空は向かい風・凍結高度 2800 m・峰に雲）。峠経由は たにま（標高 950 m・草地 600 m）を出てすぐ かざこし峠 3000 m を越え、こうげん（標高 1700 m）で空気の薄さに出会う。南回り（ひくね経由 504 km）は山が低い（1800 m）が遠く、向かい風と前線。1日目は 7:00 に出る |
| くもじ峠を越えて島へ ★★ | 1930年 エイミー・ジョンソンの英豪飛行（トルコの山脈、ティモール海） | 山を越えてから海を渡る。峠経由は やまあい（標高 850 m・草地 520 m）を出てすぐ くもじ峠 2500 m（巡航型では上昇が間に合わない）。直行（207 km）は あおがね岳 2600 m の横を越えるが、山が遠いので巡航型でも越えられる。そのあと うらの から海の上 135 km で あかね島へ。山を避けるなら南の浜 みなみうら から こばと島（草地 460 m）づたいに、海の上 130 km と 120 km を2回 |
| おおわだつみを無着陸で ★★★ | 1919年 アルコックとブラウン、1927年 リンドバーグ | 南回りの直行は海の上 508 km（満タン・最良燃費でも残りは十数 L）。北回りは海の上 390 km だが、凍結高度 1700 m と海霧のあいだを飛び、きたのみさきの滑走路は 380 m |
| はるか海を渡り 山脈を越える ★★★ | 1930年 メルモーズの南大西洋横断、ギヨメのアンデス越え | 長い海のあとに高い山。プロペラは旅のあいだ替えられないので、どちらに合わせるかが悩みどころ。まっすぐの海（海の上 375 km・どの高さでも向かい風）は巡航型なら満タンで余裕があるが、上昇型では予備燃料ぎりぎり。むこうはまを出てすぐの ゆきがね峠 3400 m は上昇型なら越えられ、中間は燃料を軽くすれば越えられ、巡航型では越えられない（さわべ経由で にしの峠 2400 m へ回る）。島づたい（なかのしま：草地 470 m・整備場なし）なら海は 190 km と 200 km。1日目は 7:00 に出る |

**山の上**（地図の ▲）：
- **高いほど上昇率が落ちる**：1000 m までは変わらず、そこから下がって 3000 m で半分、高度の上限 3600 m で約 3分の1（`climbAltitudeFactor`）。かざこし峠は谷を出てすぐの急な上りなので、巡航型で重いと上昇が間に合わず山にぶつかる（上昇型・中間なら越えられる）。
- **高い飛行場**：離陸距離は密度高度で伸びる（もとからある 4.5 の式）。こうげんでは巡航型で多めに積むと飛び立てない。
- **3D の景色**：尾根をコースを横切る山なみとして描き、凍結高度より上の峰には雪をかぶせる。山の上を飛んでいるあいだは地面を岩の色にする。コースの真上の峰はその地点の地面の高さと同じで、15 km より外の峰は見た目だけ少し高いことがある。

**海の上**（地図の青い点線）のルール：
- 海の上の地面は 0 m。エンジン停止・燃料切れ・プロペラの故障・日没などで止まると**着水**になる（畑への不時着ではない）。
- 海の上では、予備のプロペラを積んでいても交換して飛び続けることはできない（降りる畑がない）。
- **引き返し限界点**：今の速さと燃料流量のまま、引き返しても予備燃料（8 L）を残して出発地に戻れるいちばん遠い地点。飛行中の帯に赤い線で出し、越えたら一度だけ知らせる。引き返すときの確認には、戻るのに要る燃料の見積もりを出す。
- どこが海かは、コースごとの陸地の形（`land`）から 1 km きざみで決まる。

### 評価の項目（格納庫）・うわさ話・記録と実績

- **評価の項目を先に見せる**：格納庫の上に、着いたときの評価の4項目（日数・燃費・機体の状態・安全な判断、各25点）、減点になる飛び方、ランクの境目、「4つの学び」の題を出す。このコースの自己ベストがあれば並べる。数字は `src/game/evaluation.ts` の `SCORE_GUIDE`・`RANK_FROM`・`LESSON_TITLES` を最後の評価と共用している。
- **うわさ話**（`src/game/rumors.ts`）：格納庫と経由地で、次に飛ぶ区間について土地の人（村の人・漁師・給油係・郵便機の操縦士・宿のおかみ。すべて架空）のうわさを2つまで出す。区間のデータ（山の高さ、海の上の長さ、午後の積乱雲、峰にかかる雲、凍結高度、着く先の朝霧・短い滑走路・整備場の有無、高さごとの風、湿度の差、乱気流）から作るので、予報や地図と食い違わない。いちばん大事な1つは必ず出し、2つ目は旅の乱数の種と日付で選ぶ（描き直しても変わらない）。
- **記録**（`src/game/records.ts`）：目的地に着くと、コースごとの自己ベスト（点数・ランク・何日目）を残す。コースのカードに自己ベストを出す。ブラウザの localStorage（`plane.progress`）に保存し、保存できない環境でも遊べる。
- **実績**：10個。手に入れるまでは題名を「？？？」で伏せ、手がかりだけ見せる（コース選びの下の「実績」）。はじめての横断／一日で渡りきる（チュートリアル以外）／引き返して、また飛んだ／海の上の 500 km（1回の旅で）／峰の横を越えて（3000 m 以上の山の区間）／燃費名人（1 L で 7 km 以上）／大洋を越えた／名パイロット（S）／計器だけを信じて（リアル）／すべての空を越えて（チュートリアル以外の6コース）。
- **増設タンク**：「大洋を越えた」（★★★ おおわだつみを渡りきる）で使えるようになる。格納庫の燃料の量のタブで積むと、燃料の容量が 80 L → 120 L（`BIG_TANK_L`）。タンクそのものの重さは入れていない（積んだ燃料の重さで、離陸と上昇が苦しくなる）。
- **実績の獲得メッセージ**（`src/ui/achievementPopup.ts`）：目的地に着いて実績を手に入れると、画面のまん中にメダルと「実績を獲得！」を1つずつ出し、チャイムを鳴らす。クリック・Enter・スペースで次へ（さわらなくても数秒で進む）、Esc で閉じる。
- **最後の画面**：自己ベストを更新したか、新しい実績（使えるようになったもの）を出す。「次の旅」では、次のランクまであと何点か・いちばん取りこぼした項目と伸ばし方を整備士が言い、次のコースをすすめる（まだ渡っていないコースをやさしい順に。全部渡ったら、S をとれていない点のいちばん低いコース）。

### 整備士のおすすめセッティング（格納庫）

格納庫の「整備士のおすすめセッティングにする」を押すと、選んでいる最初の行き先から目的地までのいちばん近い道順を見て、ピッチ・燃料・装備を決め、理由を整備士が箇条書きで説明する（`src/game/recommend.ts`）。説明はボタンの下の「おすすめ内容」を開くと読める。ボルトの締め付け（A3）は自分でやる。
- **ピッチ**：1500 m 以上の山と 300 km 以上の海の両方があれば 3（中間で両立）、山だけなら 2、400 km 以上の海を一気に渡るなら 5、それ以外は 4。道の途中の飛行場で、次の区間の燃料を積んで飛び立てなければ、1つずつ上昇型に寄せる。
- **燃料**：最初の区間を教科書どおりに飛んだ見積もり × 余裕（陸 1.2・海の上 1.35）＋ 予備 8 L を、5% きざみで切り上げる。
- **装備**（枠と重さに収まる順に）：気象ラジオ（海や積乱雲）→ 前縁の保護（草地の滑走路や雨）→ 工具セット（整備場のない経由地）→ 予備のプロペラ（海のない道だけ）。重くて飛び立てなければ予備のプロペラを外す。

### 地図と行き先

行き先は**地図で選ぶ**（格納庫と経由地の画面で、つながっている飛行場をクリック）。7つの飛行場と9本の道があり、目的地 きた への行き方は大きく3通り。

| 道 | 特徴 |
|---|---|
| 山越え：みなみ → かわら → たかね → きた | いちばん近い（646 km）。山の上の雲、午後の積乱雲、乱気流 |
| 峠経由：かわら → とうげ → たかね | 区間は短いが、とうげの滑走路は 480 m の草地。重いと飛び立てない |
| 海沿い：みなみ → はまかぜ → ぬまた → きた | 山も積乱雲もないが遠い（773 km）。朝の海霧（低い雲）、ずっと向かい風 |

上の表は、本土の地図（`world.ts`。チュートリアルの元で、テストでも使う）の道。

最初は「目的地へのいちばん近い道順」の次の飛行場が選ばれている。行き先ごとに、その道で行ったときの目的地への到着見込み（何日目の何時ごろ・途中で何泊か）が出る。締め切りはない。

「最初の区間」「次の区間」のタブには、選んだ区間の**断面図**（横から見た地形・すすめの飛び方・予報の雲や雨や積乱雲・凍結高度・高度別の風）と、時間・燃料・着く先の霧のカードが出る。経由地でも格納庫（最初の区間）でも同じもの。格納庫で見る予報は、出発したあとの旅と同じ乱数の種から作るので、そのまま当日の予報になる（ピッチ・燃料・装備を変えても予報は変わらない）。

## 操作

| キー | 操作 |
|---|---|
| W / S（↑ / ↓） | C1 スロットル ±5% |
| A / D（← / →） | C2 ミクスチャー（D で薄く） |
| R / F | C4 目標高度 ±100 m |
| Q / E | 左右によける（コースから 10 km ずつ） |
| H | C3 キャブレターヒート |
| P | 気象ラジオで予報を更新（積んでいるとき） |
| U | 引き返す |
| スペース | 一時停止（ボルト締めのミニゲームでは「締める」） |

機体の点検（経由地・失敗したとき・到着したとき）は**点検図**で見せる。横から見た複葉機で エンジン（B4）・振動（B3）・機体の強度（B6）を、正面から見たプロペラの拡大図で ボルト（B1：ハブの6本のボルト）・前縁（B2：羽根の前のふち）・耐久度（B5：羽根の色と割れ）を、それぞれ色（緑・黄・赤）と吹き出しで指す。黄・赤の部分は印が点滅し、図の下に整備士のひとことが付く。

機体は木製プロペラの**複葉機**（上下2枚の主翼・翼の間の支柱と張り線・オープンコクピット）。見た目だけで、飛び方の計算は変わらない。

飛行中の画面は1画面に収まる（スクロールなし）：上の帯／景色（残りの高さを全部使う）／計器盤（横1段）。飛行メモは景色の右上に、整備士のひとことは景色の下に字幕のように重ねる。計器とレバーの大きさは画面の大きさに合わせて変わる（幅 820px 以下では、計器を横6つ小さく並べ、その下にレバーと操作）。

景色の下の帯は、上が「上から見た地図」、下が「横から見た高度の断面（山・雲・凍結高度）」。
予報は点線と確率、目で見て確かめた実際の天気は塗りで描く。

## 設計書から足したもの・決めたもの

### ステップ1
- **日没の時間制限**：4.4 の式のままだとスロットルを絞るほど燃費が良くなり、絞りきるのが正解になってしまう。そこで「日没までに着く」条件を足した。
- **スロットルの下限 20%**：4.4 の式ではスロットル0%で燃料消費0でも飛べてしまうため。
- **最良燃費〜薄すぎの間の係数**：設計書に値がないので、出力 0.96→0.90、燃料 0.85→0.80 で仮置き。
- **予備燃料 8L**：最良燃費の巡航で約30分ぶん。
- **排気温度計（EGT）**：付録B「EGTの最高温度の点が最良燃費」を計器で体験できるように追加。

### ステップ2
- **上昇と降下**：ピッチの得失（上昇力・降下時の回転の上がりすぎ）が遊びに出るように、離陸 → 上昇 → 巡航 → 降下を入れた。上昇率は「ピッチ・出力・重さ・高さ」（高さは山越えコースのときに足した。1000 m から落ち始め、5000 m で 0）、降下中は速度 +30 km/h。高度計を計器盤に追加。
- **A1 の表と 4.1 の式の食い違い**：A1 の表は「巡航型ほど降下時に回転数が上がりすぎやすい」だが、4.1 の式と付録B（静止回転数が高い＝上昇型ほどオーバースピード）は逆。実物に合う **式と付録B に合わせた**。
- **重さ**：機体と操縦者 500 kg（設計書の EMPTY_WEIGHT）、燃料 0.72 kg/L、装備は3枠・25 kg まで。
- **ボルトのゆるみ（4.6）**：飛行時間のぶんは飛びながら、湿度の差のぶんは着陸後に減らす（経由地の画面で「湿度 85% → 35%。ボルトがゆるんだ」と見せるため）。
- **A3 ミニゲーム**：押している間トルクが上がり、レンチが「カチッ」と鳴る範囲で離すと適正。3本の結果のうち悪いほうが全体の結果。不足は締め直せるが、締めすぎは取り消せない（木がつぶれる）。
- **振動による傷み**：設計書は「赤が続くと耐久度が下がる」だけなので、赤の入口で約1.5時間、ひどいと1時間足らずで割れる量にした。
- **予備のプロペラ**：飛行中にプロペラが外れたり割れたりしたとき、畑に降りて交換し、3時間遅れで飛び続けられる（一度だけ）。経由地で交換することもできる。
- **時間**：整備場での締め直し 1時間・前縁補修 2時間・エンジン整備と機体の修理 3時間、工具セットでの締め直し 30分、給油 20分、天気待ち 2時間。日没後は出発できない。
- **お金（費用）はなし**：設計書には「限られたお金」があるが、ゲームから外した。装備・燃料・整備・宿泊・着陸はすべて無料で、限りがあるのは燃料・時間・体力。舗装と未舗装の違いは、小石で前縁が傷むかどうかだけ。
- **燃料を抜く**：短い滑走路から重すぎて飛べないとき用に、燃料を減らせる。
- **飛行計画の目安**：経由地で、次の区間を「出力70%・最良燃費」で飛んだときの時間と燃料を見せる。
- **気象ラジオ**：選べるが、天気はステップ3なので今は効果なし。
- **区間のやり直し**：失敗したら「この区間をやり直す（出発前に戻る）」か「格納庫からやり直す」を選べる。

### ステップ3
- **天気の作り方**：区間ごとに「起きるかもしれない天気」のひな形（場所・高さ・午前／午後の確率）を決め、日と時間帯ごとに乱数で実際の天気を決める。予報はその確率をそのまま見せ、実際の位置は ±12 km・雲の高さは ±200 m ほどずれる。同じ日・同じ時間帯なら同じ天気なので、区間をやり直しても天気は変わらない。
- **予報と実際**：遠くの天気は予報（点線・確率）でしかわからず、雲や雨は 35 km、積乱雲は 70 km まで近づくと実際にあるかがわかる。乱気流は入ってみるまでわからない。気象ラジオは、実際の天気をすべて教えてくれる（30分に1回）。
- **操作を足した**：天気を遊びにするため、C3 キャブヒート・C4 高度（設計書の操作表にある）に加えて、「左右によける」と「引き返す」を足した。よけるときは 30° で斜めに飛ぶので、そのぶん遠回りになる。目的地が近づくと自動でコースに戻る。
- **雲の中**：4.10 の方向感覚タイマー。雲の中に 8 分（ゲーム内）いると操縦不能。画面はじわじわ傾く（ステップ5の演出を先に少しだけ）。雲から出ると少しずつ戻る。
- **積乱雲**：37 km 以内で機体が傷む（4.10）。近くは強い雨と乱気流。午後に育ちやすい。
- **機体の強度（B6）**：設計書の structureDamage を「残りの強さ 0〜100」として状態に足した。積乱雲と、乱気流の中で Va（140 km/h）を超えたときに減る。整備場で修理できる。
- **キャブレター凍結**：4.9 の式のままだと区間の中でほとんど効かないので2倍にした。凍ると吸気が詰まって回転数がじわじわ下がる（6章「回転計の針をじわじわ下げる」）。警告灯は出さない（6章：ふつうモード以上では出さない）。
- **着氷**：凍結高度より上で雲か雨に入るとプロペラに氷が付き、振動が出て効率が落ちる。下へ降りると溶ける。
- **霧**：飛行場ごとに露点を決め、気温は時刻で変わる（14時が最高、夜中は5℃低い）。気温と露点の差が2℃以下で6割、3℃以下で3割の日に霧が出る（4.10）。霧の出発地からは飛べず、霧の目的地には降りられない（上空で待つか引き返す）。
- **気温と離陸**：気温が時刻で変わるので、朝の涼しいうちは離陸距離が短い（4.5「涼しい時間を待つ」）。
- **経由地で「天気を待つ」**：2時間待つ。霧は日が高くなると晴れ、正午を過ぎると午後の天気に入れ替わる。
- **引き返した回数・待った回数**：数えておき、最後の画面に出す（勇気ある撤退ボーナスはステップ4）。

### ステップ4
- **締め切りはなし**：はじめは「航空祭（2日目 13:00）に間に合わせる」締め切りを置いていたが、外した。
- **焦り（E2）**：設計書は「予定より遅れる」と焦る（4.11 `haste += 10 × hoursBehindSchedule`）。締め切りがないので、有視界飛行の毎日の締め切りである**日没**を「予定」とした。飛行中は到着見込みが日没の30分前を過ぎるあいだ、経由地では今出ても日没の30分前までに次の行き先へ着けそうにない時間（まだ明るいうち）にいるあいだ、1時間ごとに +10。余裕があるあいだは1時間ごとに −5、夜は数えない。引き返す・天気を待つと −20（勇気ある撤退）、一晩眠ると −10。60 以上で整備士のひとことが「まあ大丈夫だろう」に変わる（雲・積乱雲・燃料不足などの危ないサインも）。どう変わっていたかは、最後のふり返りで明かす。
- **疲労（E1）**：4.11 のとおり飛行1時間ごとに +10、一晩休むと −50。60 を超えると、操作が効き始めるまでに最大3分（ゲーム内）遅れ、計器の針が最大 6% ゆっくりずれる（本人は気づきにくい）。レバーや表示は「動かしたつもりの値」を見せる。
- **最終評価**：2章の4項目を各25点。日数（1日で着けば 25・2日 18・3日 10・それ以上 0）・燃費（1 L あたりの km）・機体の状態（着いたときの平均）・安全な判断（予備燃料を守った 10 ＋ 勇気ある撤退ボーナス 引き返す 10／待つ 5（最大 10）＋ 整備 1回 2（最大 5））。危ない飛び方は減点（雲の中 1分 −2、積乱雲の近く・回転超過・乱気流で Va 超え 1分 −1、予備燃料割れの着陸 −5、最大 −30）。85 点以上 S・70 以上 A・50 以上 B。
- **4つの学びのふり返り**：1章の4つの学びごとに、旅の記録（回転超過・いちばんゆるんだボルト・燃費・焦っていた時間）から○△を付けてひとこと添える。
- **ステップ3の直し**：雲の外の空気まで湿りきっていて、湿った日はどの高度でもキャブレターが強く凍っていた。地面から離れた雲の外では、気温と露点の差を 4℃ 以上にした（雲の中は 0）。

### ステップ5
- **難易度（7章の表どおり）**：かんたん＝混合比・キャブヒート・ボルト点検の通知が自動（キャブ凍結の警告灯も出る）。ふつう＝ボルト点検の通知だけ。リアル＝自動なし、計器も数値だけ（色の帯・ゾーンの小窓・3色表示なし、数値はいつも表示）、予報の外れが大きい（位置と高さのずれ2倍、確率そのものも ±25% ずれる）。
- **ボルト点検の通知**：湿度の違う土地に着いたとき、またはボルトが 70 を下回ったとき、経由地の画面に知らせて「ボルトを締め直す」を目立たせる。飛行中は 40 を下回ると「ボルト点検」の警告灯。
- **エンジン音（6章）**：音のファイルは使わず WebAudio で作る。回転数で高さが変わり、振動でうなり、薄すぎやキャブレター凍結でバラつく。風切り音・雨音・積乱雲の遠雷も。上の「音」ボタンで切り替え（覚えておく）。ブラウザの決まりで、最初にクリックかキーを押したときから鳴る。
- **空間識失調（4.10・付録C）**：雲の中にいる時間が上限の 35% を超えると、気づかないうちに旋回降下に入る。高度が最大 300 m/分で下がり、速度が最大 +45 km/h 上がり（回転も上がる）、機体に力がかかって強度が減る。本人は水平のつもりなので、高度計の小窓は「巡航中」のまま。画面はじわじわ傾く。雲の下に抜ければ立て直せるが、山や地面まで雲なら逃げ場がない。
- **整備士のひとこと（6章「各パラメータに一行」）**：計器・レバー・警告灯・疲労と焦りのメーターをクリックすると、そのパラメータの一言が7秒出る。経由地の点検表では、黄・赤の項目に一言を添える。設計書3章の例文はそのまま使い、焦りが 60 以上なら楽観的な文になる。

### ルート計画（2章「地図上で経由地を選ぶ」）
- **地図**：7つの飛行場（みなみ・かわら・はまかぜ・とうげ・たかね・ぬまた・きた）と9本の道。距離は地図の上の位置から計算する。
- **道は両向きに飛べる**：天気のひな形と山の位置は道の片方の向きで書き、逆向きに飛ぶときは距離を数え直し、左右を入れ替え、風を反対から吹かせる。
- **到着の見込み**：行き先の一覧では、その道で行ったあと「いちばん近い道順を、ふつうの速さ（110 km/h）で飛んだら」目的地にいつ着くかを見積もる（日没までに着けない区間は翌朝に飛ぶ）。
- **飛び立てない飛行場の注意**：行き先の一覧で、今の機体（ピッチと装備）では朝に燃料を少しにしても飛び立てない飛行場には注意を出す（とうげ は上昇型なら満タンでも出られるが、巡航型はほぼ空でないと出られない）。
